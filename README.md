# LiiDi releases

Official installers and signed update manifests for Zyntopia LiiDi.

The beta is invitation-only. Downloading an installer does not grant access. No beta installer has been published yet.

This repository contains distribution material only. Application source is maintained privately.

macOS beta builds use ad hoc signing and are not notarized by Apple. Follow the release-specific installation instructions.
